# API 共通仕様

---

## エラーレスポンス形式

すべてのエラーレスポンスは以下の形式で返す。

```json
{
  "message": "エラーの概要",
  "errors": [
    { "field": "フィールド名", "message": "フィールドごとのエラーメッセージ" }
  ]
}
```

| フィールド | 型 | 説明 |
|---|---|---|
| `message` | string | エラーの概要メッセージ。常に含まれる |
| `errors` | array | フィールドごとのエラー詳細。バリデーションエラー（400）・コンフリクト（409）のみ含まれる |

> `errors` はフィールド単位のエラーが存在する場合のみ含まれる。認証失敗（401）・タイムアウト（408）などは `message` のみ返す。
